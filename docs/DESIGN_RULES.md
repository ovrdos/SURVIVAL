# SURVIVAL Design Rules

1. Reuse POSTAL functionality whenever possible.
2. Do not replace working systems without a demonstrated need.
3. Prefer asset replacement over engine modification.
4. Prefer configuration/data changes over new code.
5. Modernize graphics and animation before adding functionality.
6. Preserve the classic isometric gameplay orientation.
7. Keep the game board readable at the original gameplay scale.
8. Do not introduce unnecessary physics systems.
9. Do not introduce unnecessary AI systems into the code.
10. Every new system requires justification.
